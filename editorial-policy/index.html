편집 원칙

SpareTrip은 여행자가 출국 전 실제로 확인해야 하는 순서와 판단 기준을 정리합니다.

작성 기준

  • 여권, 항공권, 숙소, 입국 서류처럼 실행 순서가 중요한 항목을 우선합니다.
  • 공식 조건이 수시로 바뀌는 항목은 최종 확인이 필요하다고 명확히 표시합니다.
  • 광고성 추천보다 초보 여행자의 실수 방지와 선택 기준을 먼저 다룹니다.

출처 확인 기준

입국 조건, 공항 이용, 수하물, 교통패스, 보험 약관처럼 변경 가능성이 높은 정보는 정부기관, 공항, 항공사, 교통기관, 보험사 등 1차 출처를 우선 확인 대상으로 둡니다. 공식 출처가 없는 개인 경험형 정보는 일반 참고 정보로 구분합니다.

수정 기준

항공, 입국, 교통, 보험 관련 조건은 변경 가능성이 높기 때문에 주기적으로 점검하고 오래된 내용은 보강하거나 제외합니다.

오류 제보

글 내용이 실제 공식 안내와 다르거나 오래된 경우 문의 페이지의 이메일로 알려주시면 확인 후 수정합니다.

가치가 낮은 글을 피하기 위한 기준

SpareTrip은 단순 요약, 출처 없는 단정, 같은 문장 구조의 반복을 줄이고 글마다 독립적인 판단표와 확인 순서를 둡니다.

  • 공식 정보가 필요한 글에는 1차 확인 링크를 둡니다.
  • 각 글은 최소 하나 이상의 상황별 판단표를 포함합니다.
  • 이미지는 장식보다 글의 주제와 맞는 맥락 설명을 함께 표기합니다.
  • 미완성 글이나 얇은 글은 색인 대상에서 제외하거나 허브 글로 보강합니다.

보강 또는 제외 기준

글의 본문이 짧거나, 독립적인 판단 기준 없이 다른 글을 반복하거나, 공식 링크를 확인할 수 없는 변동 정보만 담고 있으면 먼저 보강 대상으로 분류합니다. 보강으로도 독자에게 새로운 결정을 돕지 못하는 글은 색인 대상에서 제외합니다.

업데이트 기준

공식 기관의 안내가 바뀌었거나 독자의 오류 제보가 근거와 함께 접수되면 해당 글을 재검토합니다. 단순히 날짜만 바꾸지 않고, 실제로 달라진 조건과 여행자가 다시 확인할 항목을 함께 수정합니다.

정보를 구분해서 쓰는 방법

정보 유형본문 처리독자에게 알리는 방식
변동 가능성이 높은 사실공식 페이지를 우선 확인하고 요약 범위를 최소화합니다.출국·결제 전 다시 확인할 공식 링크를 둡니다.
일반적인 준비 원칙특정 기관의 조건처럼 단정하지 않고 판단 순서로 설명합니다.개인 상황과 상품 약관에 따라 달라질 수 있음을 표시합니다.
운영자의 정리·판단여러 확인 항목을 초보자가 실행할 순서로 재구성합니다.‘SpareTrip 판단 노트’로 공식 사실과 구분합니다.
이미지주제와 관련된 공개 이미지 또는 자체 편집 이미지만 사용합니다.글 상단에 출처 성격과 맥락을 표기합니다.

검토와 수정의 흐름

  1. 새 글을 발행하기 전 제목, 설명, 내부 연결, 공식 확인 링크가 주제와 맞는지 점검합니다.
  2. 발행 후 링크 오류, 중복 이미지, 유사한 문단, 오래된 조건을 정기적으로 확인합니다.
  3. 독자 제보는 페이지 주소와 근거를 기준으로 사실관계를 검토합니다.
  4. 오류가 확인되면 내용을 고치고, 확인이 어려운 변동 정보는 단정 문구를 줄이거나 글을 보강합니다.

광고·제휴와 편집 분리

광고가 표시되거나 외부 링크가 있더라도 광고주나 외부 사업자가 글의 제목, 순서, 판단표, 결론을 정하지 않습니다. 특정 항공권·숙소·보험 상품의 구매를 권유하기 위해 내용을 작성하지 않으며, 광고와 편집 콘텐츠의 구분 원칙은 면책 및 광고 고지에서 안내합니다.
